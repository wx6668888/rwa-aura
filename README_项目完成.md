## 🚀 快速开始

### 1. 安装依赖

```bash
# 根目录
npm install

# 后端
cd backend && npm install

# 前端
cd frontend && npm install
```

### 2. 启动本地开发

```bash
# 启动 Hardhat 节点（终端1）
npm run node

# 部署合约（终端2）
npm run deploy:local

# 启动后端（终端3）
cd backend && npm run dev

# 启动前端（终端4）
cd frontend && npm run dev
```

### 3. 运行测试

```bash
# 运行所有测试
npm test

# 运行集成测试
npx hardhat test test/FullIntegration.test.ts

# 运行安全测试
npx hardhat test test/Security.test.ts
```
