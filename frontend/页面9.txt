PANCAKESWAP INTEGRATION NOTE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
When "PancakeSwap 实时" selected:
Create hooks/useTokenPrice.ts with:

  fetchPancakeSwapPrice():
    GraphQL query to PancakeSwap V3 subgraph
    endpoint: https://api.thegraph.com/subgraphs/
    name/pancakeswap/exchange-v3-bsc
    Query: token price, 24h volume, 
    price change from pool data.
    Refresh interval: 15 seconds.
    Loading state: skeleton on all values.
    Error state: 
      "数据获取失败，显示缓存数据" 
      warning chip, falls back to last known.

  fetchOHLCV(timeframe):
    Fetch candle data from PancakeSwap subgraph
    poolDayDatas / poolHourDatas queries.
    Map to lightweight-charts OHLCV format.

All API calls: show subtle 
"更新中..." spinner next to live indicator.
