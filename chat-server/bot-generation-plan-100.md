## 自动生成脚本设计

### generate-bot.js 功能
```javascript
// 主要功能
1. 读取基础模板 (RWA_BOT_001)
2. 根据配置生成差异化数据
3. 生成唯一的钱包地址
4. 生成合理的投资时间线
5. 分配社交圈子
6. 生成方言和口头禅
7. 验证数据一致性
8. 输出JSON文件

// 输入参数
- botId: 机器人编号 (1-100)
- occupation: 职业类型
- location: 地域
- investmentAmount: 投资金额
- nodeLevel: 节点等级
- entryDate: 入场日期
- cluster: 所属圈子
- personality: 性格标签

// 输出
- personas/RWA_BOT_XXX.json
```

### validate-consistency.js 功能
```javascript
// 验证项目
1. JSON格式正确性
2. 必需字段完整性
3. 数据类型正确性
4. 时间线逻辑性
5. 金额一致性
6. 社交关系双向性
7. 钱包地址唯一性
8. 方言地域匹配性

// 输出
- 验证报告 (validation-report.json)
- 错误列表
- 警告列表
- 建议修复方案
```
