# 数据库配置指南

## 1. 安装 MySQL

确保您的系统已安装 MySQL 5.7 或更高版本。

## 2. 创建数据库和用户

### 方式一：使用 MySQL 命令行

```sql
-- 登录 MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE IF NOT EXISTS rwa_protocol CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建用户（请修改密码）
CREATE USER IF NOT EXISTS 'rwa_user'@'localhost' IDENTIFIED BY 'your_password_here';

-- 授予权限
GRANT ALL PRIVILEGES ON rwa_protocol.* TO 'rwa_user'@'localhost';
FLUSH PRIVILEGES;
```

### 方式二：使用 phpMyAdmin 或其他 MySQL 管理工具

1. 创建数据库：`rwa_protocol`
2. 创建用户：`rwa_user`
3. 授予所有权限

## 3. 初始化数据库表结构

```bash
# 进入后端目录
cd backend

# 使用 MySQL 客户端执行 SQL 文件
mysql -u rwa_user -p rwa_protocol < src/config/database.sql
```

或者直接在 MySQL 客户端中执行 `src/config/database.sql` 文件的内容。

## 4. 配置环境变量

在 `backend` 目录下创建 `.env` 文件：

```env
# Database Configuration
DB_HOST=localhost
DB_PORT=3306
DB_USER=rwa_user
DB_PASSWORD=your_password_here
DB_NAME=rwa_protocol

# Server Configuration
PORT=3001

# BSC Network Configuration (可选，用于链上事件监听)
BSC_RPC_URL=https://bsc-dataseed.binance.org
BSC_TESTNET_RPC_URL=https://data-seed-prebsc-1-s1.binance.org:8545

# Contract Addresses (可选)
STAKING_CONTRACT_ADDRESS=0xYourStakingContractAddress
RWA_TOKEN_ADDRESS=0xYourRWATokenAddress
USDT_TOKEN_ADDRESS=0x55d398326f99059fF775485246999027B3197955

# Backend Configuration (可选)
BACKEND_PRIVATE_KEY=0xYourPrivateKeyHere
CONFIRMATION_BLOCKS=12
POLL_INTERVAL=5000

# Redis Configuration (可选，用于价格缓存)
REDIS_HOST=localhost
REDIS_PORT=6379

# CORS Configuration
CORS_ORIGIN=http://localhost:3000
```

## 5. 启动后端服务

```bash
cd backend
npm run dev
```

## 6. 验证数据库连接

后端服务启动后，您应该看到：

```
✅ Database connected
✅ HTTP server listening on port 3001
```

如果看到数据库连接错误，请检查：
1. MySQL 服务是否正在运行
2. 数据库用户名和密码是否正确
3. 数据库 `rwa_protocol` 是否已创建
4. 用户 `rwa_user` 是否有权限访问数据库

## 7. 测试 API

```bash
# 健康检查
curl http://localhost:3001/health

# 全局统计
curl http://localhost:3001/api/stats/global

# 查询用户（替换地址）
curl http://localhost:3001/api/user/0xYourUserAddress
```

## 常见问题

### 问题 1: 数据库连接失败

**错误信息**: `ER_ACCESS_DENIED_ERROR` 或 `ECONNREFUSED`

**解决方案**:
- 检查 MySQL 服务是否运行
- 验证用户名和密码
- 检查用户权限

### 问题 2: 数据库不存在

**错误信息**: `Unknown database 'rwa_protocol'`

**解决方案**:
- 执行 `CREATE DATABASE rwa_protocol;`
- 或修改 `.env` 中的 `DB_NAME`

### 问题 3: 表不存在

**错误信息**: `Table 'rwa_protocol.users' doesn't exist`

**解决方案**:
- 执行 `src/config/database.sql` 文件初始化表结构

## 快速启动脚本

如果您使用 Windows PowerShell，可以使用以下命令快速配置：

```powershell
# 1. 创建数据库和用户（需要 MySQL root 权限）
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS rwa_protocol CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; CREATE USER IF NOT EXISTS 'rwa_user'@'localhost' IDENTIFIED BY 'rwa_password_123'; GRANT ALL PRIVILEGES ON rwa_protocol.* TO 'rwa_user'@'localhost'; FLUSH PRIVILEGES;"

# 2. 初始化表结构
mysql -u rwa_user -prwa_password_123 rwa_protocol < backend/src/config/database.sql

# 3. 创建 .env 文件（需要手动编辑密码）
Copy-Item backend\.env.example backend\.env
# 然后编辑 backend\.env 文件，修改密码为 rwa_password_123
```
