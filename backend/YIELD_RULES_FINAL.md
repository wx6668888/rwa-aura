# RWA收益计算系统 - 最终规则

## 基础参数

- **基础日收益率**: 0.8% (0.008)
- **锁仓加成（乘数）**:
  - 灵活(0天): 1.0 → 收益率 0.8%
  - 30天: 1.3 → 收益率 1.04%
  - 90天: 1.6 → 收益率 1.28%
  - 180天: 2.0 → 收益率 1.6%
  - 365天: 2.5 → 收益率 2.0%

## 核心公式

```
收益 = 金额 × 日收益率 × (持有秒数 / 86400)
日收益率 = 0.008 × 锁仓乘数
```

## 10条核心规则

### 1. 收益计算周期
- **固定周期**: 昨日08:00 → 今日08:00（24小时）
- **按秒精确计算**，不简化

### 2. 质押生效时间
- **立即生效**，不是T+1
- 昨日12:00质押 → 今日08:00结算 = 20小时收益

### 3. 锁仓到期
- **无宽限期**，到期立即转灵活
- 定时任务每10分钟检查并转换

### 4. 提现处理
- 到期后全部转灵活
- 提现时从灵活余额扣除

### 5. 追加质押
- **方案B**: 新建独立的锁仓记录

### 6. 收益提现
- 不影响本金锁仓状态和收益率

### 7. 多次质押
- 按余额快照分段计算

### 8. EventMonitor实时同步
- 质押/提现时自动记录快照

### 9. 定时任务校验
- 每10分钟检查锁仓到期

### 10. 防重复发放
- 记录settlement_time，检查是否已结算

## 实现架构

### 核心服务
1. **DailySettlementService** - 每日结算（每天08:00）
2. **PreciseYieldCalculator** - 按秒精确计算
3. **BalanceSnapshotService** - 记录余额快照
4. **LockMaturityService** - 锁仓到期处理（每10分钟）

### 数据表
- `balance_snapshots` - 余额快照
- `yield_settlements` - 收益结算记录
- `lock_maturity_events` - 锁仓到期事件
- `fund_activities` - 资金活动记录

### 定时任务
- 每日收益: `0 0 * * *` (每天00:00 UTC = 北京08:00)
- 锁仓到期: `*/10 * * * *` (每10分钟)
- 价格刷新: `*/5 * * * *` (每5分钟)
- 节点同步: `0 * * * *` (每小时)

## 计算示例

### 示例1: 灵活质押
- 质押: 1000 USDT
- 时间: 昨日12:00 → 今日08:00 (20小时 = 72000秒)
- 收益率: 0.8%
- 收益 = (1000/0.85) × 0.008 × (72000/86400) = 7.84 RWA

### 示例2: 90天锁仓
- 质押: 1000 USDT
- 时间: 昨日08:00 → 今日08:00 (24小时)
- 收益率: 0.8% × 1.6 = 1.28%
- 收益 = (1000/0.85) × 0.0128 × (86400/86400) = 15.06 RWA

## 数据一致性保证

1. **EventMonitor** 监听链上事件，实时同步
2. **防重复检查** 结算前查询 `yield_settlements` 表
3. **快照记录** 每次质押/提现/到期都记录快照
4. **定时校验** 每10分钟检查锁仓到期状态
