# 启动数据库（MySQL）

本后端使用 **MySQL**，默认连接 `localhost:3306`，数据库名 `rwa_protocol`，用户 `rwa_user`（见 `backend/.env`）。

## 一、若已安装 MySQL（Windows 服务）

在 **以管理员身份打开** 的 PowerShell 或 CMD 中执行：

```powershell
# 进入后端目录
cd "e:\MyRWA_Project\rwa aura\backend"

# 方式 1：用脚本自动尝试常见服务名并启动
.\start-database.ps1

# 方式 2：手动查服务名再启动
# 查看 MySQL 相关服务
Get-Service *mysql*

# 启动（把 MySQL80 换成你机器上的实际服务名）
net start MySQL80
# 或
Start-Service MySQL80
```

常见服务名：`MySQL80`、`MySQL57`、`MySQL`。

## 二、若尚未安装 MySQL

1. **下载安装包**  
   https://dev.mysql.com/downloads/installer/  
   选 Windows 版 MySQL Installer（如 mysql-installer-community）。

2. **安装时注意**  
   - 选择安装 **MySQL Server**。  
   - 在配置步骤里勾选 **“Configure MySQL Server as a Windows Service”**，并设为开机启动（可选）。  
   - 记住设置的 **root 密码**。

3. **安装完成后**  
   - 若未设为自动启动，可用上面「一」中的命令启动服务。  
   - 再在 `backend` 目录运行 **数据库初始化**：  
     `.\setup-database.ps1`  
     （会创建数据库 `rwa_protocol`、用户 `rwa_user` 并导入表结构，并生成/更新 `.env` 中的 DB 配置。）

## 三、验证是否启动成功

- 在 CMD/PowerShell 中（若已把 MySQL 的 `bin` 加入 PATH）：  
  `mysql -u rwa_user -p -h 127.0.0.1 -e "SELECT 1"`  
  输入 `backend/.env` 里 `DB_PASSWORD` 的密码，能执行成功即说明数据库已启动且配置正确。
- 或直接启动后端：`npm run dev`，能连上并无 DB 报错即表示数据库已正常。

## 四、本机未安装 MySQL 时（用 Docker，需先装 Docker Desktop）

若已安装 Docker，可在项目根目录用容器起一个 MySQL：

```bash
docker run -d --name rwa-mysql -p 3306:3306 -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=rwa_protocol -e MYSQL_USER=rwa_user -e MYSQL_PASSWORD=rwa_password mysql:8
```

然后把 `backend/.env` 中 DB 配置设为：  
`DB_HOST=localhost`，`DB_PORT=3306`，`DB_USER=rwa_user`，`DB_PASSWORD=rwa_password`，`DB_NAME=rwa_protocol`。  
最后执行 `backend` 下的 `setup-database.ps1` 或手动导入 `backend/src/config/database.sql` 初始化表结构。
