# 如何获取合约代码

## ⚠️ 当前状态

脚本已运行，但需要 **BSCScan API Key** 才能获取合约源代码。

---

## 🔑 方法1：获取 BSCScan API Key（推荐）

### 步骤：

1. **访问 BSCScan**
   - 打开 https://bscscan.com/apis

2. **注册/登录账号**
   - 如果没有账号，先注册
   - 如果已有账号，直接登录

3. **申请 API Key**
   - 点击 "Add" 创建新的 API Key
   - 选择 "Free" 计划（每天 5 次/秒的请求限制）
   - 复制生成的 API Key

4. **设置 API Key**
   - 在项目根目录创建 `.env` 文件
   - 添加以下内容：
     ```
     BSCSCAN_API_KEY=your_api_key_here
     ```

5. **重新运行脚本**
   ```bash
   node scripts/analyze-contracts.js
   ```

## 🚀 快速开始

### 如果您有 BSCScan API Key：

1. 创建 `.env` 文件：
   ```bash
   echo BSCSCAN_API_KEY=your_api_key_here > .env
   ```

2. 运行脚本：
   ```bash
   node scripts/analyze-contracts.js
   ```

### 如果您没有 API Key：

1. 访问 https://bscscan.com/apis 申请免费 API Key
