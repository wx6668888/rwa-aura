## ⚠️ 关键注意事项

### 4 个硬性安全要求（必须严格执行）

1. **合约发奖必须"先锁后查后加"**
   - updateUserRewards 函数必须严格按 Checks-Effects-Interactions 模式
   - 第一步：所有校验
   - 第二步：设置锁定标记（processedStakes[stakeId] = true）
   - 第三步：更新状态
   - 第四步：外部调用

2. **后端调用合约必须设置单次最高限额**
   - maxRewardPerCall = 10000 USDT（默认）
   - 防止后端被黑导致合约被掏空

3. **数据库必须存储 18 位整数**
   - 所有金额字段使用 DECIMAL(38, 0)
   - 不能用小数，避免精度丢失

4. **级差查询必须用精确匹配**
   - 使用 referral_relations 表
   - 禁止 LIKE 模糊匹配

### 前端紧急提取 UI 要求

必须包含以下 4 个部分：
1. 🔴 入口处红色气泡提示
2. 🔴 确认对话框详细说明
3. 🔴 交易结果显示对比
4. 🔴 FAQ 部分解释
