# 质押收益计算

## 📊 收益率配置

### 基础日收益率
**0.8%/天**

### 锁仓加成
| 锁仓期 | 加成 | 实际日收益率 |
|--------|------|--------------|
| 灵活质押 | 0% | 0.8% |
| 锁仓30天 | +30% | 1.04% |
| 锁仓90天 | +60% | 1.28% |
| 锁仓180天 | +100% | 1.6% |
| 锁仓365天 | +150% | 2.0% |

**年化收益率**：
- 灵活：0.8% × 365 = 292%
- 锁仓365天：2.0% × 365 = 730%

## 📝 数据结构

### balance_snapshots表
记录用户余额的**变化量**（不是余额本身）：

| 字段 | 说明 | 示例 |
|------|------|------|
| user_address | 用户地址 | 0xabc... |
| asset_type | 资产类型 | 'USDT' 或 'RWA' |
| balance_type | 余额类型 | 'flexible', 'locked_30', 'locked_90', 'locked_180', 'locked_365' |
| amount | 变化量 | 质押：+1000e18，提现：-500e18 |
| timestamp | 时间戳（秒） | 1710000000 |
| event_type | 事件类型 | 'stake', 'withdraw', 'mature' |
| lock_end_time | 锁仓到期时间 | timestamp + 30*86400 |

**关键点**：
- ✅ 质押记录正数
- ✅ 提现记录负数
- ✅ 到期转换记录正数（balance_type='flexible'）

## 🔢 收益计算流程

### 步骤1：获取所有快照
```sql
SELECT * FROM balance_snapshots
WHERE user_address = ? 
  AND asset_type = ? 
  AND timestamp <= 结算结束时间
ORDER BY timestamp ASC
```

### 步骤2：计算初始余额
累加结算周期开始前的所有快照，得到5种类型的余额：
- flexible
- locked_30
- locked_90
- locked_180
- locked_365

### 步骤3：逐段计算收益
```
初始余额 = 累加(结算开始前的所有快照)
当前余额 = 初始余额
上次时间 = 结算开始时间

for 每个快照 in 结算周期内:
  if 快照时间 > 上次时间:
    收益 += 计算收益(当前余额, 上次时间, 快照时间)
  
  当前余额 += 快照的变化量
  上次时间 = 快照时间

if 上次时间 < 结算结束时间:
  收益 += 计算收益(当前余额, 上次时间, 结算结束时间)
```

### 步骤4：累加所有时间段收益
返回总收益

## 📐 收益计算公式

### RWA质押
```
收益(wei) = 余额(wei) × 日收益率 × 持续秒数 / 86400
```

**示例**：
- 余额：1000 RWA = 1000e18 wei
- 收益率：0.8%/天 = 0.008
- 时长：1小时 = 3600秒
- 收益 = 1000e18 × 0.008 × 3600 / 86400 = 0.333e18 = 0.333 RWA

### USDT质押
```
USDT转18位小数 = USDT(6位) × 1e12
RWA等价 = USDT(18位) / 0.85
收益(wei) = RWA等价 × 日收益率 × 持续秒数 / 86400
```

**示例**：
- 余额：1000 USDT = 1000e6 wei
- 转18位：1000e6 × 1e12 = 1000e18
- RWA等价：1000e18 / 0.85 = 1176.47e18
- 收益率：1.04%/天（锁仓30天）
- 时长：21小时 = 75600秒
- 收益 = 1176.47e18 × 0.0104 × 75600 / 86400 = 10.71e18 = 10.71 RWA

## 💡 完整示例

### 场景
- **Day1 10:00** - 质押1000 RWA（灵活）
- **Day1 10:30** - 提现500 RWA
- **Day1 11:00** - 质押1000 USDT（锁仓30天）
- **Day2 08:00** - 结算

### balance_snapshots记录
```
10:00 - amount: +1000e18, balance_type: flexible, event_type: stake
10:30 - amount: -500e18, balance_type: flexible, event_type: withdraw
11:00 - amount: +1000e6, balance_type: locked_30, event_type: stake
```

### 计算过程

**初始余额（10:00之前）**：
- flexible: 0
- locked_30: 0

**时间段1：10:00 → 10:30（1800秒）**
- 余额：flexible = 1000 RWA
- 收益率：0.8%
- 收益 = 1000e18 × 0.008 × 1800 / 86400 = **0.167 RWA**

**时间段2：10:30 → 11:00（1800秒）**
- 余额：flexible = 500 RWA（1000 - 500）
- 收益率：0.8%
- 收益 = 500e18 × 0.008 × 1800 / 86400 = **0.083 RWA**

**时间段3：11:00 → 次日08:00（75600秒）**

RWA部分：
- 余额：flexible = 500 RWA
- 收益率：0.8%
- 收益 = 500e18 × 0.008 × 75600 / 86400 = **3.5 RWA**

USDT部分：
- 余额：locked_30 = 1000 USDT
- RWA等价：1176.47e18
- 收益率：1.04%
- 收益 = 1176.47e18 × 0.0104 × 75600 / 86400 = **10.71 RWA**

**总收益**：0.167 + 0.083 + 3.5 + 10.71 = **14.46 RWA**

## 🔒 锁仓到期处理

### 定时任务
- **执行频率**：每10分钟（`'*/10 * * * *'`）
- **服务**：LockMaturityService

### 处理流程

**1. 查询到期锁仓**
```sql
SELECT * FROM usdt_locked_principals 
WHERE lock_end_time <= NOW() 
  AND is_withdrawn = FALSE 
  AND is_matured = FALSE

SELECT * FROM rwa_locked_principals 
WHERE lock_end_time <= NOW() 
  AND is_withdrawn = FALSE 
  AND is_matured = FALSE
```

**2. 转为灵活质押**
- 更新锁仓记录：`is_matured = TRUE`
- 记录balance_snapshots：
  - amount: 原锁仓金额（正数）
  - balance_type: 'flexible'
  - event_type: 'mature'
- 记录lock_maturity_events表
- 记录fund_activities表

### 对收益计算的影响

**收益率变化**：
- 锁仓期间：按locked_X的收益率计算
- 到期后：自动变为flexible，按0.8%计算

**示例**：
```
Day 1: 质押1000 RWA锁仓30天
Day 1-30: 1000 RWA × 1.04%/天
Day 30: 到期，记录mature事件
Day 31+: 1000 RWA × 0.8%/天
```

### balance_snapshots记录示例

**质押时**：
```
amount: +1000e18
balance_type: 'locked_30'
event_type: 'stake'
lock_end_time: timestamp + 30*86400
```

**到期时**：
```
amount: +1000e18
balance_type: 'flexible'
event_type: 'mature'
```

**计算器处理**：
- 到期前：locked_30余额1000，收益率1.04%
- 到期后：flexible余额增加1000，收益率0.8%
