## 1. 欢迎您

感谢您了解 **RWA 协议**相关服务。本手册面向 **普通用户（C 端）**，用尽量简洁的语言说明：您可以在平台上做什么、需要准备什么、以及需要注意的风险。

**重要说明：** 数字资产与智能合约存在价格波动与技术风险；本手册中的功能描述、费率与规则 **以您使用时官网实际展示及链上智能合约为准**。若官网或合约有更新，请以最新公告为准。

## 2. RWA 协议是什么

**RWA 协议**是一套运行在 **BSC 主网**上的去中心化应用，主要帮助用户完成：

- 使用 **USDT** 或 **RWA 代币**进行 **链上质押**；  
- 在允许的路径下进行 **代币兑换**；  
- 在规则允许时 **提取本金或收益**（含推荐奖励、项目分红等，具体以页面与合约为准）；  
- 在链上 **查看**自己的操作记录与资产变动。

您始终通过 **加密钱包**（如 MetaMask 等）连接网络并确认交易；**私钥与助记词由您本人保管**，平台不会、也不应向您索要私钥或助记词。

## 3. 使用前准备

| 项目 | 说明 |
|------|------|
| **钱包** | 安装支持 BSC 的 Web3 钱包，并备份好 **助记词 / 私钥**（勿截图发群、勿交给「客服」）。 |

| **USDT / RWA** | 质押或兑换前，请确保钱包内有足够代币；**代币合约地址请以官网公示或区块链浏览器核对为准**，谨防假币。 |

## 5. 质押说明

### 5.1 基本流程

1. 打开官网，**连接钱包**。  
2. 进入 **质押**页面，选择 **USDT** 或 **RWA**。  
3. 输入数量，选择 **锁仓期限**（若有）。  
4. 若页面提示需 **授权（Approve）**，请先完成授权再质押。  
5. 在钱包中 **确认交易**；完成后可在 **仪表盘**或区块浏览器查看记录。

### 5.2 推荐关系（若产品支持）

- 部分场景下，**首次**建立质押时可能 **绑定推荐人**；是否可更改、是否永久有效，**以智能合约规则为准**。  
- 请仅从 **官方渠道**获取邀请链接，谨防仿冒网站。

### 5.3 收益与展示

- 页面上可能展示 **日化、团队、节点**等相关说明，属于 **规则性描述**。  
- **不构成保本或固定收益承诺**；实际到账受 **合约参数、市场波动、系统结算时间**等影响。  
- **收益与本金是否分离、如何提现**，请以 **提现页面**与合约规则为准。

## 6. 兑换说明

- 兑换前通常需要先对代币进行 **授权**。  
- 显示价格多来自 **报价接口或流动性池**，**实际成交价格与滑点以链上结果为准**。  
- 若兑换失败，常见原因包括：滑点过小、流动性不足、网络拥堵、用户取消交易等。

## 7. 提现与资产类型

不同资产可能对应 **不同入口与规则**（以下名称以官网中文界面为准）：

| 类型 | 用户理解要点 |
|------|----------------|
| **本金** | 锁仓类本金可能与 **到期时间**有关；灵活类规则不同，**以页面与合约为准**。 |
| **收益** | 可能与 **RWA 或 USDT** 等形式相关，提现前注意 **最低额度、手续费、到账时间**。 |
| **推荐奖励** | 常为 **USDT** 形式；可能有 **结算周期**与 **最低提现额**（例如不低于一定 USDT），以页面为准。 |
| **项目分红** | 可能有 **固定结算周期**（如按月），以页面与公告为准。 |
| **一键提取** | 可能一次发起多步链上操作，请仔细阅读页面说明并确认 **Gas 与笔数**。 |

**手续费提示：** 链上提现类操作往往存在 **费率或分配**（例如用于协议内不同地址的分配），**具体比例以合约及当时规则为准**，建议在操作前阅读页面说明或帮助中心。

## 10. 安全与风险提示

请务必阅读并理解以下风险：

1. **智能合约风险**：合约可能存在漏洞或遭受攻击，导致资产损失。  
2. **市场风险**：代币价格波动可能导致资产贬值。  
3. **网络风险**：错误网络、错误合约地址、钓鱼网站可能导致资产被盗。  
4. **私钥风险**：**任何索要助记词/私钥的「客服」均为诈骗**。  
5. **政策与合规风险**：不同司法辖区对数字资产的监管不同，请自行遵守当地法律。  
6. **非存款、非理财**：本协议 **不是银行存款**，不提供存款保险或法定本息保证。

**官网认准：以 rwa.lat（或官方公告的正式域名）为准**；请收藏官方链接，勿通过搜索引擎随机点击不明广告链接。

## 11. 常见问题

**问：为什么交易一直 pending？**  
答：多半是 BSC 网络拥堵或 Gas 过低；可在钱包中加速或等待，必要时咨询钱包官方文档。

**问：为什么提示授权失败或质押失败？**  
答：检查网络是否为 BSC、代币余额是否足够、是否已 Approve、滑点/参数是否满足合约要求。

**问：为什么页面数据与钱包不一致？**  
答：页面数据可能来自 **索引延迟** 或 **统计口径**（如团队统计方式）；可与区块浏览器上的链上记录核对。

**问：忘记助记词怎么办？**  
答：无法找回。**请务必在创建钱包时备份**，并保存在安全离线环境。
