# 项目安全扫描报告（木马/恶意代码检查）

**扫描时间**：按当前代码库状态  
**结论**：**未发现木马或恶意代码**。以下为检查项与建议。

---

## 一、已检查项

### 1. 危险函数与执行链

- **eval / new Function / atob 执行代码**：仅在 `frontend/.next` 构建产物中出现（Next.js/Turbopack 正常逻辑），**业务源码中未使用**。
- **child_process / exec / spawn**：**未使用**。
- **后端 db.exec**：仅用于 SQLite 初始化 schema（`meta-relayer.ts`），**属正常用途**。

### 2. 安装/构建钩子

- **package.json**（根目录、frontend、backend）：**无 postinstall / preinstall / install 等会拉取或执行外部脚本的钩子**，未见恶意安装脚本。

### 3. 网络请求与外部域名

- **前端 fetch/axios**：仅请求：
  - 本地或配置的后端（如 `NEXT_PUBLIC_RELAYER_URL`、`NEXT_PUBLIC_API_URL`，默认 localhost:3001）
  - 已知服务：WalletConnect、BSC RPC、BSCScan、ethereum.org、Chainlink 等
- **未发现**向不明域名上传数据、私钥或敏感信息的逻辑。
- 后端脚本中的 `curl`/`https.get` 仅出现在文档或测试脚本中，且目标为本地或 BSCScan 等已知 API。

### 4. 敏感信息与私钥

- **PRIVATE_KEY / RELAYER_PRIVATE_KEY / BACKEND_PRIVATE_KEY**：仅在 **backend、scripts、hardhat 配置** 中通过 `process.env` 使用，**未在前端或公开仓库中硬编码**。
- 前端仅使用 `NEXT_PUBLIC_*` 等公开配置，**未发现**收集或上传钱包私钥/助记词的代码。

### 5. 依赖

- **根目录**：Hardhat、OpenZeppelin、ethers、axios、dotenv 等常见链上/脚本依赖。
- **frontend**：Next、React、wagmi、RainbowKit、viem、Radix 等常见前端/钱包库。
- **backend**：express、mysql2、ethers、better-sqlite3、helmet 等常见后端库。
- **未发现**明显恶意或 typosquat 包名。

### 6. 后端 API 与用户输入

- 用户输入（如 `address`、`req.body`）用于：
  - 合约只读调用（如 nonce、链上数据）
  - 数据库查询（地址、分页等）
- **admin 表名**：`tableName` 经**白名单**校验（`allowedTables`），再参与查询，**未发现**通过表名注入的恶意逻辑。
- **未发现**将 `req.body`/`req.query` 传入 `eval`、`exec` 或类似动态代码执行。

### 7. 长 Base64 / 混淆串

- 仅发现用于**合约事件解码的示例十六进制数据**（如 `decode-event.ts`、`parse-log.js`），为正常 ABI 数据，**非混淆或外链载荷**。

---

## 二、非木马但可加强的方面（建议）

1. **admin 排序参数**：`sortBy` / `sortOrder` 若直接拼进 SQL 的 `ORDER BY`，存在 SQL 注入风险。建议对 `sortBy` 做白名单或映射，`sortOrder` 限定为 `ASC`/`DESC`。
2. **dangerouslySetInnerHTML**：用于公告等场景时，若内容来自后台或用户，建议做 HTML  sanitize（如 DOMPurify），防止 XSS。
3. **CORS**：当前 `origin: process.env.CORS_ORIGIN || '*'` 在正式环境建议改为具体前端域名，减少跨域滥用可能。

---

## 三、总结

| 检查项           | 结果     |
|------------------|----------|
| 恶意/动态代码执行 | 未发现   |
| 恶意安装/构建脚本 | 未发现   |
| 异常外联/数据外泄 | 未发现   |
| 私钥/助记词泄露   | 未发现   |
| 依赖包明显异常   | 未发现   |

**结论**：当前仓库**未检出木马或恶意代码**。建议定期更新依赖、做好 `.env` 与私钥管理，并按上文建议加固 admin 与 CORS、XSS 防护。
