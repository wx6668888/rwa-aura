## 一、入门与钱包

### 1. 什么是 RWA 协议？

RWA Protocol 是运行在币安智能链（BSC）上的去中心化质押协议。

**用户能做什么**：通过质押 USDT 或 RWA 代币，获得每日 RWA 静态收益；若满足节点等级条件，当**下级用户充值（质押）**时，您还可按本次质押金额的比例获得 USDT 推荐奖励（见「节点与推荐」）。协议采用 **50/50 资金模型**：您质押的资金中，50% 进入国库储备，50% 进入社区奖励池，用于发放每日收益与推荐/节点奖励。

**举例**：您质押 10,000 USDT，则 5,000 USDT 进入国库、5,000 USDT 进入社区池；您按「有效质押」份额每日领取 RWA 收益。若您有下级且为推荐人，当其**每次充值质押**时，您会按等级比例从该次质押金额中获得 USDT 奖励。

---

### 2. RWA 代币是什么？用来做什么？

**RWA** 是 RWA Protocol 的**协议代币**，在 BSC 上发行（ERC-20/BEP-20），是协议内收益发放、质押参与和部分功能的主要载体。

**主要用途**：

| 用途 | 说明 |
|------|------|
| **每日静态收益** | 您质押 USDT 或 RWA 后，协议按日发放的**收益以 RWA 代币**形式结算（如基础 0.8% 日息 × 锁仓倍数），可在「提现」页申请提现 RWA。 |
| **RWA 质押** | 您可以直接用 **RWA** 参与质押：将 RWA 存入合约获得 stRWA 凭证，按日领取 RWA 收益，并可选择锁仓期限（灵活/30/90/180/365 天），锁仓到期后可解锁取回 RWA 本金。 |
| **购买抽奖券** | 在「幸运抽奖」页，可使用 **RWA** 购买实时/周/月/年奖池的抽奖券，参与开奖与奖金分配。 |
| **兑换** | 在「兑换」页可用 **USDT 购买 RWA**；持有 RWA 也可在支持的 DEX 或协议内进行兑换、流转。 |

**如何获得 RWA**：① 在协议「兑换」页用 USDT 购买；② 通过质押 USDT 或 RWA 获得每日收益（以 RWA 发放）；③ 抽奖中奖（若奖金为 RWA）；④ 从其他用户或交易所/ DEX 购入（以实际上线情况为准）。

**说明**：RWA 价格会随市场波动，收益与提现时的实际价值以当时价格为准；请仅投入可承受损失的资金。

### 3. 如何开始使用？分几步？

共 **四步**，适合从未用过钱包的新手：

**① 准备钱包**  
下载 OKX、币安等 App，或安装 MetaMask（小狐狸）等浏览器插件，创建或导入一个 Web3 钱包，并备份好助记词。

**② 充值 USDT**  
向该钱包充值 USDT，且必须是 **BEP-20（BSC 链）**。例如在币安提币时选择「BSC (BEP-20)」，填写您钱包的 BSC 收款地址。单笔建议先小额测试（如 100～200 USDT）。

**③ 连接本站**  
打开 RWA 协议官网，点击右上角「连接钱包」，在弹窗中选择您使用的钱包并授权。连接成功后页面会显示您的地址缩写（如 0x1234…5678）。

**④ 首次质押**  
进入「质押」页面，输入金额（**最低 100 USDT 等值**）、选择锁仓期限，若有推荐人则在「推荐人地址」一栏填写其钱包地址（仅首次可填，填后永久绑定）。先授权（Approve）再点击质押并确认交易，等待链上确认即可。

**举例**：小明第一次用 500 USDT 质押、选择 30 天锁仓并填写了推荐人 A 的地址；链上确认后，小明每日获得 RWA 收益，A 则在该笔质押时按等级获得一定比例的 USDT 推荐奖励（按 500 USDT 计算），且小明以后无法再更改推荐人。

### 4. 支持哪些钱包？

支持所有 **兼容 BSC（币安智能链）** 的钱包，例如：

- **OKX Wallet**（OKX App 内或插件）
- **币安 Web3 钱包**（币安 App 内）
- **MetaMask**（小狐狸，浏览器插件或 App）
- **TokenPocket**、**Trust Wallet** 等
- 其他支持 WalletConnect 的钱包，可通过扫码或弹窗连接

**建议**：若在手机端使用，优先用 **OKX 或币安 App 内置浏览器** 打开本站再连接钱包，网络与授权体验更稳定；国内用户若遇连接转圈，可尝试切换网络或使用上述内置浏览器。

### 5. 如何连接钱包？

**步骤**：打开网站 → 点击右上角「连接钱包」→ 在弹窗中选择您正在使用的钱包（如 MetaMask、OKX、币安等）→ 在钱包弹窗中点击「授权」或「连接」→ 连接成功后，网站右上角会显示您的地址（如 0x1234…5678）。

**重要**：连接前请确认钱包已切换到 **BSC 主网**（Chain ID: 56）。若当前是以太坊主网或其他链，本站会提示「不支持的链」，需在钱包内手动添加或切换到 BSC 后再连接。否则无法进行质押、提现等操作。

### 6. 什么是 Gas？为什么需要 BNB？

**Gas** 是区块链上执行一笔交易时消耗的「矿工费」。在 BSC 上，Gas 用 **BNB** 支付，而不是 USDT 或 RWA。

**典型消耗**：一次质押、一次提现、一次授权，通常各需约 **0.001～0.003 BNB**（约合几美分到几毛钱，随 BNB 价格波动）。若钱包里只有 USDT 没有 BNB，交易会因「Gas 不足」而失败。

**建议**：在参与质押或提现前，先保证钱包内有至少 **0.01～0.05 BNB**，用于多笔操作的 Gas。例如：首次需「授权 + 质押」两笔交易，约 0.002×2 ≈ 0.004 BNB；之后每次提现约 0.001～0.003 BNB。

## 二、充值与入金

### 1. 如何获得 USDT？

您可以从 **中心化交易所**（如币安、OKX、火币等）用法币或其它币种购买 USDT，然后通过「提币」把 USDT 提到自己的链上钱包。

**关键**：提币时必须选择 **BEP-20（BSC 链）**，并填写您钱包的 **BSC 收款地址**。若误选 ERC-20（以太坊）或其它链，资产将无法在本站使用，且跨链找回流程复杂、有风险。**举例**：您在币安有 1000 USDT，提币时网络选「BSC (BEP-20)」，地址填 MetaMask 显示的 BSC 地址，数量填 500，到账后即可在 RWA 协议进行质押。

---

### 2. 如何从交易所提币到钱包？

**步骤**（以常见交易所为例）：

1. 登录交易所，找到「提币」或「提现」。
2. 币种选择 **USDT**。
3. 网络选择 **BSC (BEP-20)** 或「BNB Smart Chain」（不同交易所名称可能略有差异，务必选 BSC 链）。
4. 收款地址：从您的钱包（如 MetaMask）复制 **BSC 主网地址**（以 0x 开头，42 位），粘贴到交易所提币地址栏。
5. 输入提币数量，确认手续费与到账数量，完成安全验证（短信/邮箱/谷歌验证等）。

**到账时间**：通常几分钟到十几分钟。**举例**：提币 500 USDT，手续费约 0.8～1 USDT，实际到账约 499 USDT。首次建议先提 100～200 USDT 测试，确认到账无误后再大额操作。

---

### 3. 如何选择 BSC 网络？

在钱包中需添加或切换到 **BSC 主网**，常见参数如下：

- **网络名称**：BNB Smart Chain 或 BSC
- **链 ID (Chain ID)**：**56**
- **RPC URL**：可由 BSC 官方文档或钱包默认列表获取
- **区块浏览器**：https://bscscan.com

本站仅支持 BSC 主网（及项目方配置的测试网）。若您当前在以太坊（Chain ID 1）或其它链，页面会提示「请切换到 BSC」。在 MetaMask 中可点击顶部网络名称 → 添加网络 → 填写上述参数；在 OKX/币安 App 中一般选择「BSC 主网」即可。

---

### 4. 最低充值/质押金额是多少？

单笔最低质押金额为 **100 USDT 等值**。不论您用 USDT 还是 RWA 质押，系统都会按**当时价格**折算成等值 USDT 判断是否达到门槛。

**举例**：  
- 若用 USDT 质押，最少需输入 100 USDT。  
- 若用 RWA 质押，且当时 RWA 价格为 0.5 美元，则至少需 100 ÷ 0.5 = **200 RWA** 才能通过最低校验。  
低于 100 USDT 等值的输入将无法提交质押交易。

## 三、质押与收益

### 1. 什么是质押？

**质押**是指您将 USDT 或 RWA 代币转入协议智能合约，从而获得「每日 RWA 收益」和（在满足条件时）「推荐/节点 USDT 动态奖励」的过程。

**资金去向**：您转入的金额会按 **50% 进国库、50% 进社区池** 的比例分配；您并不直接「拿回」那 50% 国库部分，而是通过「质押份额」每天从协议领取 RWA 收益。收益在满足**冷却期、最低提现额、手续费**等规则后，可在「提现」页申请转出。

**举例**：您质押 2,000 USDT，则 1,000 进国库、1,000 进社区池；您按协议规则每日获得约 2,000×0.8%＝16 USDT 等值的 RWA（具体以当日 RWA 价格折算），并可在一段时间后提现 RWA 或领取 USDT 动态奖励。

---

### 2. USDT 质押和 RWA 质押有什么区别？

**USDT 质押**：  
- 您向合约转入 **USDT**。  
- 合约按日发放 **RWA 代币** 作为静态收益（如基础 0.8% 日息 × 锁仓倍数）。  
- 您若存在推荐人且满足节点条件，在您**每次质押时**推荐人/上级会按本次质押金额的比例获得 **USDT** 形式的推荐奖励（非每日收益抽成）。  
- 资金同样 50% 国库、50% 社区池。

**RWA 质押**：  
- 您向合约转入 **RWA**。  
- 合约给您 **stRWA** 凭证，按日计 **RWA** 收益。  
- 您可选择 **锁仓期限**（如 30/90/180/365 天）；锁仓部分到期后，可通过「stRWA 解锁」换回 RWA 本金。  
- 资金同样 50/50 分配。

**举例**：  
- 用 1,000 USDT 质押（灵活锁仓）：每日约 1,000×0.8%＝8 USDT 等值 RWA，不锁本金。  
- 用 1,000 USDT 等值的 RWA 质押并选 90 天锁仓：每日收益有锁仓加成（如 +60%），但 90 天内该部分本金不能取回，到期后可解锁为 RWA 再提走。

### 3. 授权（Approve）是什么？为什么要做两笔交易？

第一次质押或兑换时，钱包会先弹出一笔 **「授权」或「Approve」** 交易，很多新手会疑惑甚至担心是不是被骗。这是**区块链上的正常、必要步骤**，不是多扣您一笔钱，也不是诈骗。

**授权（Approve）是什么？**  
在链上，您的 **USDT、RWA** 等代币平时只归您自己控制。智能合约**不能**未经您同意就从您钱包里转走代币。  
**授权**就是您**明确允许**「某个合约在您设定的额度内，可以动用您的某种代币」。例如：您对质押合约做一次 USDT 授权、额度 10,000，之后该合约才有权限在您点击「质押」时，把您要质押的那笔 USDT 从您钱包转进合约。授权**不会**立刻转走您的币，只是给合约一个「允许动用」的额度；真正转走币的是您后面发起的**第二笔交易**（质押或兑换）。

**为什么要做两笔交易？**  
- **第一笔：Approve（授权）**  
  您允许合约使用您的 USDT（或 RWA）。这笔交易**不转走您要质押的金额**，只写入一条「该用户允许本合约最多动用多少」的记录；通常只需支付少量 **Gas（BNB）**。  
- **第二笔：Stake / 兑换**  
  您点击「质押」或「兑换」后发起的交易，这时合约才会在您已授权的额度内，把您输入的金额从钱包转出并完成质押或兑换。

**常见误解**：  
- 「授权是不是把币转给项目方了？」——不是。授权只是「允许合约在您操作时转币」，不会在授权这一刻转走您的 USDT/RWA。  
- 「为什么第一次要两笔，后面有时只要一笔？」——同一代币对同一合约**只需授权一次**（或当额度用完后再次授权）。第一次质押/兑换需要「授权 + 实际操作」两笔；之后若额度够用，只需发起「质押/兑换」那一笔。

**总结**：授权是链上 DeFi 的通用机制，目的是**在您知情同意的前提下**让合约能执行「转走您的代币」的操作，两笔交易是正常流程，不是重复扣款也不是骗局。您只需按钱包提示先确认授权、再确认质押/兑换即可。

### 4. 质押页面显示「余额不足」但我钱包里有 USDT，是怎么回事？

常见原因如下，可逐条对照：

1. **网络不对：钱包里的是其他链上的 USDT**  
   协议只认 **BSC（币安智能链）** 上的 USDT。若您的 USDT 在**以太坊（ERC-20）** 或其它链上，质押页读取的是 BSC 余额，会显示为 0 或不足。**解决**：在交易所提币时选择 **BEP-20 / BSC**，把 USDT 提到您当前连接的钱包在 BSC 上的地址；或先通过跨链/桥把资产转到 BSC。

2. **钱包未切换到 BSC 主网**  
   页面连接的是当前钱包所选网络。若您选的是「以太坊主网」等，合约会按 BSC 查余额，可能显示为 0。**解决**：在钱包里把网络切换为 **BSC 主网（Chain ID: 56）**，再刷新页面查看余额。

3. **需要预留 BNB 当 Gas**  
   质押和授权都要消耗 **BNB** 作为 Gas。若钱包里**只有 USDT、没有 BNB**，交易可能因「Gas 不足」失败，部分前端会以「余额不足」或类似提示出现。**解决**：在钱包中保留少量 BNB（例如 0.01～0.05），再重试质押。

4. **授权额度不足**  
   若您之前授权过该合约的 USDT 额度小于本次要质押的金额，需要先**再次授权**（Approve）提高额度，或授权「无限额度」（部分页面提供该选项），然后再点质押。

5. **页面显示延迟或缓存**  
   刚提币到账或刚切换网络时，页面可能还未刷新出最新余额。**解决**：刷新页面，或重新连接钱包后再试。

若以上都确认无误仍提示余额不足，请核对钱包内 BSC 上的 USDT 余额（可在 BSCScan 等区块浏览器查看），并带上**钱包地址、网络、截图**联系客服便于排查。

### 5. 质押页面一直显示「等待确认」，交易卡住了怎么办？

这种情况和「链上交易待确认」不同：**页面一直转圈、显示「等待确认」不消失**，多半是**前端在等钱包或链上回调**时卡住，而不是链上没确认。

**建议按顺序做：**

1. **先看钱包**：打开钱包 App 或插件，看是否有一笔「待签名」或「待确认」的质押/授权交易。若钱包里已确认成功，说明链上已上链，只是页面没刷新。
2. **不要重复点**：若链上已成功，再点一次「质押」可能造成重复质押。先关闭当前页签，重新打开「质押」页或「仪表板」，看总质押和余额是否已更新。
3. **刷新或重连**：刷新页面（F5 或下拉刷新），或断开钱包后重新连接，再查看资产与记录。
4. **查链上**：用钱包地址在 **BSCScan** 查最近交易，若能看到成功的质押/授权记录，说明资金已生效，可忽略前端卡住，稍后再登或换设备查看。
5. **仍卡住**：清除浏览器缓存、换浏览器（建议 Chrome/Brave）或换设备（如用 OKX/币安 App 内置浏览器）再试；若仍无效，带上**钱包地址、大致时间、截图**联系客服。

**和「交易待确认」的区别**：「交易待确认」一般是链上拥堵、交易在链上 Pending；「等待确认」卡死多为前端或钱包回调未返回，按上面步骤排查即可。

### 6. 我能取消质押吗？

**不能。** 协议**不支持「取消质押」或「撤销质押」**，质押一旦上链即生效，无法像撤销订单一样直接退回。

- **若只是想拿回资金**：  
  - **RWA 质押且选了锁仓**：需等**锁仓到期**后，在「提现」页用 **stRWA 解锁** 取回 RWA 本金。  
  - **RWA 灵活质押**：未锁仓的那 50% 本金可在「提现」页按「灵活质押本金」规则随时提回。  
  - **USDT 质押**：若是**灵活仓位**，可在「提现」页的**本金提取区**正常提取 USDT 本金；若是**锁仓仓位**，需等**锁仓到期**后正常提取，未到期时才可考虑使用**紧急提取**。详见「什么是紧急提取」。
- **总结**：没有「取消质押」按钮；正常退出要按您的**仓位类型**走对应的本金提取路径，只有**未到期的锁仓 USDT**才需要紧急提取。质押前请确认金额与锁仓期。

---

### 7. stRWA 和 RWA 有什么区别？

**RWA** 是协议的**流通代币**，可在钱包里持有、转账、用于质押或兑换等；在 DEX 或协议「兑换」页可交易。

**stRWA** 是您用 **RWA 做质押并选择了锁仓**（如 30/90/180/365 天）时，合约发给您的**质押凭证**，代表「锁在合约里的那部分 RWA 本金」。  
- 锁仓期内：您持有的是 **stRWA**，不能当 RWA 直接转出或当本金提走；合约会按日给您发 **RWA 收益**。  
- 锁仓到期后：在「提现」页的 **stRWA 解锁** 中，把 stRWA 换回 **RWA**，才能转回钱包或继续使用。

**简单对照**：RWA = 可自由使用的代币；stRWA = 锁仓本金对应的「凭证」，到期解锁后变回 RWA。未锁仓的 RWA 质押只有收益、没有 stRWA（灵活质押的未锁仓本金直接以 RWA 形式可提）。

---

### 8. 我能同时有多笔质押吗？

**可以。** 协议支持同一地址**多笔质押**，您可以分批存入、并选择不同的锁仓期限，多笔会合并计入您的总质押与收益。

- **分批质押**：例如今天质押 1,000 USDT、下周再质押 2,000 USDT，两笔都会记录在您名下；您的**总质押**与**每日收益**会按所有未赎回的质押合并计算（含不同锁仓倍数），可在「仪表板」与「提现」页查看汇总。
- **不同锁仓期叠加**：例如一笔选 30 天锁仓、另一笔选 90 天锁仓，两笔同时存在；各自到期后，对应部分的 stRWA（若为 RWA 质押）或锁仓规则按单笔分别处理。USDT 质押的多笔也会按各自锁仓期参与收益倍数计算。
- **USDT 与 RWA 可同时有**：您既可以有 USDT 质押（拿 RWA 收益），也可以有 RWA 质押（拿 stRWA 与 RWA 收益），两者并存；提现时「可提 RWA」会合并显示 USDT 质押与 RWA 质押的已结算收益。

**说明**：每笔质押会生成独立的 stakeId 等链上记录，但前端与合约会按**同一地址**汇总您的总质押、可提收益与可领 USDT 奖励，您无需「合并」多笔，按页面提示操作即可。

### 9. 锁仓期限有哪些？收益倍数怎么算？

支持的锁仓选项及收益加成（以当前协议为例）如下：

| 锁仓期限 | 收益加成（相对灵活） | 说明 |
|----------|----------------------|------|
| 灵活     | 无加成               | 本金可随时参与「未锁仓部分」提现 |
| 30 天    | +30%                 | 30 天内该部分本金不可取回 |
| 90 天    | +60%                 | 90 天内该部分本金不可取回 |
| 180 天   | +100%                | 180 天内该部分本金不可取回 |
| 365 天   | +150%                | 365 天内该部分本金不可取回 |

**计算方式**：每日静态收益 ≈ 质押 USDT 等值 × **基础日息 0.8%** × (1 + 锁仓加成比例)，结算为 RWA（按当日价格）。

**举例**：  
- 灵活：质押 10,000 USDT，每日 10,000×0.8%＝80 USDT 等值 RWA。  
- 180 天锁仓（+100%）：同一 10,000 USDT，每日 10,000×0.8%×2＝**160** USDT 等值 RWA；但 180 天内该 10,000 对应的 stRWA 不能解锁，到期后才可操作「stRWA 解锁」取回 RWA。

具体倍数与选项以质押页和合约为准。

---

### 10. 每日收益如何计算？

公式（示意）：  
**每日静态 RWA 收益 ≈ 您的质押 USDT 等值 × 基础日息 0.8% × 锁仓倍数**

结果按**当日 RWA 价格**折算成 RWA 数量发放。锁仓倍数：灵活=1，30 天≈1.3，90 天≈1.6，180 天=2，365 天=2.5（以页面为准）。

**举例**：  
- 质押 **5,000 USDT**，选择 **90 天锁仓**（+60%），当日 RWA 价格 **1 美元**。  
  - 日息：5,000 × 0.8% × 1.6 ＝ 64 USDT 等值  
  - 获得 RWA 数量：64 ÷ 1 ＝ **64 RWA/天**  
- 若 RWA 价格为 **0.5 美元**，则 64 USDT 等值 ＝ 64 ÷ 0.5 ＝ **128 RWA/天**。

动态奖励（推荐/节点）按等级比例以 **USDT** 单独计算，在「提现」页的 USDT 奖励卡片中领取。实际以合约与前端展示为准。

---

### 11. 收益什么时候到账？如何查看？

**结算时间**：每日 **UTC 0:00**（北京时间 8:00）进行一次结算；到账可能有数分钟到约 **2 小时** 的链上延迟。

**如何查看**：  
- **仪表板** →「最近动态」：可看到每日收益记录。  
- **提现页**：可看到「可提 RWA」与「可领 USDT 奖励」金额。

**举例**：您在 3 月 5 日质押，3 月 6 日 UTC 0:00 结算后，大约在 3 月 6 日 8:00～10:00（北京时间）之间可在页面看到 3 月 6 日的收益。若超过 24 小时仍无记录，请确认未触发紧急提取等异常，必要时联系客服并提供钱包地址。

## 四、提现与解锁

### 1. 如何提现 RWA 收益？

进入「提现」页面，在 **RWA 提现** 卡片中会显示：  
- 可提的 **已结算 RWA 收益**（USDT 质押与 RWA 质押产生的每日 RWA 收益）。

点击「提现」→ 在钱包中确认交易并支付 Gas（少量 BNB）即可。

**重要**：提现页现在把**收益提现**和**本金提取**拆分开了。  
- **RWA 提现卡片**只处理已结算的 **RWA 收益**。  
- **本金提取区**单独处理 **USDT 灵活本金、USDT 到期锁仓本金、RWA 灵活本金、RWA 到期锁仓本金**。  
- **到期 RWA 锁仓本金**可以选择**立即到账**或 **stRWA 模式**；**USDT 本金**按标准立即到账路径结算。  

**举例**：如果您有 300 RWA 收益和 200 RWA 灵活本金，那么 300 RWA 走收益卡片，200 RWA 走本金提取区；如果某笔到期 RWA 锁仓本金选择 **stRWA 模式**，则该笔会按 **120%** 铸造成锁仓 30 天的 stRWA。

---

#### 灵活质押本金可以主动提取吗？选择灵活质押如何提现？

**可以，灵活质押的本金支持用户主动提取。**

- **适用场景**：现在 **USDT 灵活本金** 与 **RWA 灵活本金** 都支持主动提取；此外，**到期锁仓本金**也有独立的到期提取入口。
- **提现入口**：进入「提现」页后，在 **本金提取区** 分别操作；收益与本金不再混在同一张卡片中。
- **操作方式**：  
  - **USDT 灵活本金 / RWA 灵活本金**：按页面可提数量发起提取，走**立即到账**路径并统一收取 **8% 手续费**。  
  - **USDT 到期锁仓本金**：到期后可正常提取，也按统一 **8% 手续费**结算。  
  - **RWA 到期锁仓本金**：可选择**立即到账**，或改走 **stRWA 模式**，即 **0 手续费 + 20% 加成**，但会再锁 **30 天**。
- **说明**：只有**未到期的锁仓 USDT** 才需要走紧急提取；灵活 USDT 并不是只能靠紧急退出。

---

### 2. 收益是自动打到钱包还是需要手动领取？

**需要您主动操作「提现/领取」，收益不会自动打到您的钱包。**

很多用户会以为收益会像银行利息一样自动到账，在本协议中并非如此：

- **RWA 静态收益（每日 0.8% 等）**：协议会按日**结算**到您在合约内的可提额（rwaPending），但**不会自动转进您的钱包**。您需要打开「**提现**」页，在 **RWA 提现** 卡片中查看可提金额，输入数量后点击「提现」并确认交易，RWA 才会从合约转入您的钱包。不操作就不会到账。
- **USDT 推荐/节点奖励**：同样会**记在链上**、显示在「提现」页的 USDT 奖励卡片中，但需要您点击「**领取**」并确认交易，USDT 才会打入您的钱包。

**总结**：收益是**先结算到合约/链上记录**，再由您**主动发起提现或领取**才会真正进钱包；每次操作会消耗少量 BNB 作为 Gas。建议定期打开「提现」页查看可提 RWA 与可领 USDT，按需操作。

---

### 3. 提现冷却期和手续费是多少？

规则要点（以当前协议为例）：

| 项目     | 规则说明 |
|----------|----------|
| 最低提现 | 不低于 **100**（按当前提现路径对应的 RWA 或 USDT 本金额） |
| 冷却期   | 两次提现之间需间隔 **24 小时**；未满 24 小时按钮会显示倒计时 |
| 立即到账手续费 | 统一 **8%**：**3% 回购/销毁 + 3% Treasury + 2% 社区池** |
| stRWA 模式 | **0% 手续费**，按 **120%** 铸造 stRWA，并锁仓 **30 天** |
| Gas     | 需钱包内有少量 BNB 支付 BSC 链上 Gas（约 0.001～0.003 BNB） |

**举例**：  
- 您立即提现 **100 RWA**：到账 **92 RWA**；其中 **3 RWA** 用于回购/销毁、**3 RWA** 进入 Treasury、**2 RWA** 留在社区池。  
- 若选择 **stRWA 模式**：则会获得 **120 stRWA**，并锁仓 **30 天**，没有立即提现手续费。  
- 若当前可提金额低于 **100**，则未达到统一最低门槛，需等更多收益累积或本金满足条件后再操作。

### 3.1 提现后多久到账？

提现（RWA 或 USDT）与领取 USDT 奖励均为**链上交易**，到账时间取决于 BSC 网络确认与钱包刷新。

**一般情况**：  
- **链上确认**：BSC 出块约 **3 秒** 一块，您的提现/领取交易被打包后，通常 **几秒到 1 分钟内** 即可在链上确认（Success）。一旦交易状态为成功，合约已将 RWA 或 USDT 转至您的地址，即**链上已到账**。  
- **钱包显示**：部分钱包在链上确认后会有 **数秒到几十秒** 的余额刷新延迟；可下拉刷新或稍等片刻再查看余额。若在 BSCScan 上查该笔交易已成功且 Transfer 接收方是您的地址，则资产已在您地址下，多为钱包展示延迟。

**可能变慢的情况**：  
- **网络拥堵**：BSC 链上交易较多时，打包可能延迟，确认时间可能延长到数分钟。可在钱包内对该笔交易使用「加速」提高 Gas 后重试或等待。  
- **Gas 不足**：若提交时 Gas 设得过低，交易可能长时间 Pending 甚至失败，需重新发起并支付足够 Gas。

**总结**：正常网络下，提现/领取在您**确认交易后约 1 分钟内**链上到账；钱包余额显示可能再晚几秒到几十秒。若超过 2～3 分钟仍无记录，请到 BSCScan 用交易哈希或您的地址查询该笔交易状态；若显示成功但钱包仍无余额，请参考「提现后 RWA 没到钱包怎么查？」。

### 4. 什么是 stRWA 解锁？如何操作？

**stRWA** 是协议使用的质押凭证代币。在当前机制下，若您在提现时选择 **stRWA 模式**，协议会直接按 **120%** 铸造成带 **30 天锁仓**的 stRWA，而不是立即到账。

**操作**：进入提现页 → 选择 **stRWA 模式** 或查看 **stRWA 解锁** 区域 → 确认可转出/可解锁数量与到期时间 → 锁仓结束后，按页面展示的实时合约流程进行转换或解锁。

**举例**：您提现 **100 RWA** 并选择 **stRWA 模式**，则会获得 **120 stRWA**；但这部分 stRWA 需先锁满 **30 天**，之后才能进入正常的解锁/转换流程。

### 5. 如何领取 USDT 推荐奖励？

推荐/节点产生的 **动态奖励以 USDT 形式** 记录在链上。在「提现」页找到 **USDT 奖励领取** 卡片，会显示当前可领的 USDT 金额。点击「领取」→ 在钱包中确认交易并支付 Gas，USDT 即会打入您的钱包。

**说明**：推荐奖励是在**下级用户每次质押（充值）**时按本次质押金额和您的等级比例发放的，不是按下级每日收益结算。**举例**：您的直推用户本次质押了 1,000 USDT，您为 L3 节点（8% 比例），则您获得 1,000×8%＝**80 USDT** 推荐奖励；该 80 USDT 会累加在可领额中，您随时可点「领取」提走，每次领取需少量 BNB 作为 Gas。

### 6. 什么是紧急提取？有什么后果？

**紧急提取**现在只适用于**尚未到期的锁仓 USDT 仓位**。它是特殊情况下的提前退出方式，对被选中的那笔锁仓仓位来说仍然是**不可逆**的。

**资金逻辑**：可退本金按**已完成整天数**计算，公式为：  
手续费前可退金额 = 合约侧本金 × 已完成天数 / 总锁仓天数  
之后再扣统一 **8%** 立即退出手续费，其中 **3% 回购/销毁 + 3% Treasury + 2% 社区池**。

**重要说明**：新紧急退出流程返还的是 **USDT**，不是 RWA；同时也**不会清空**您尚未提取的 **RWA 收益**，它只关闭您所选中的那一笔锁仓 USDT 本金仓位。

**举例**：您做了一笔 **30 天锁仓**，在**已完成 3 个整天**后发起紧急退出，则返还进度为 **3 / 30 = 10%**。也就是说，只有**合约侧本金的 10%** 可以先进入结算，再扣除统一 **8%** 退出手续费。若锁仓已经到期，请直接走正常本金提取流程，不要再用紧急退出。

### 7. 为什么我的可提 RWA 金额和我计算的不一样？

常见原因是 **RWA 价格波动** 和 **展示口径不同**。

- **链上按「数量」记，您可能按「金额」算**：可提额在合约里是 **RWA 数量**（枚），页面可能同时显示「约等于多少 USDT」。您若用「每日 0.8% × 质押 USDT」算的是** USDT 等值**，再除以「您心里用的 RWA 单价」得到 RWA 数量；若当前 RWA 价格和您用的单价不一致，算出来的数量就会和页面不一致。
- **RWA 价格变动**：收益发放时按**当日/当时**价格折算成 RWA 数量；之后 RWA 涨跌，您用现在的价格反推「应该有多少枚」，就会和链上已锁定的数量对不上。**以页面或链上显示的可提 RWA 数量为准**，金额仅供参考。
- **手续费与冷却**：立即到账型提现统一按 **8%** 规则结算，且最低提现门槛统一为 **100**；页面展示的可能是「可提数量」或「扣费后预估到账」，和您「本金×日息×天数」的毛估会有差异。

**建议**：以提现页或仪表板显示的**可提 RWA 数量**为准；若需核对，可在区块浏览器用您的地址查看合约中的 rwaPending 等数据。

### 8. 提现后 RWA 一直没到钱包，怎么查？

若**交易在页面或钱包里已显示成功**，但钱包余额没变，可按下面排查：

1. **确认链与地址**：确认钱包当前选的是 **BSC 主网**，且查看余额的地址和提现时使用的**是同一个地址**（多账户时易搞错）。
2. **看代币是否添加**：钱包若未「添加」RWA 代币，可能不显示余额。在钱包里添加 **RWA 合约地址**（以官网或 BSCScan 为准）后，再查余额。
3. **查链上记录**：用您的地址在 **BSCScan** 查该笔提现交易的详情：若状态为 Success，且 Transfer 事件里接收方是您的地址，则链上已到账，多半是钱包展示或代币未添加问题。
4. **延迟与刷新**：链上确认后，部分钱包有数秒到几十秒的刷新延迟；可下拉刷新余额或稍后再看。
5. **仍异常**：保存该笔交易的 **TX Hash**，联系客服时提供「钱包地址 + TX Hash + 提现大致时间」，便于排查。

### 9. USDT 奖励和 RWA 收益需要分开领取吗？

**需要。** 这是**两个独立的入口**，分别操作才会到账，很多人只操作了一个就以为都领了。

- **RWA 收益**：在「提现」页的 **RWA 提现** 卡片中操作。这里提的是「每日静态收益」等以 RWA 形式结算的部分；点击「提现」、确认交易后，RWA 会进您的钱包。
- **USDT 奖励**：在「提现」页的 **USDT 奖励领取** 卡片中操作。这里领的是推荐/节点等**动态奖励**，以 USDT 形式发放；点击「领取」、确认交易后，USDT 会进您的钱包。

两笔互不影响：领了 RWA 不会自动带出 USDT，领了 USDT 也不会自动带出 RWA。若两种都有余额，需要**分别各点一次**提现/领取。每次操作都会消耗少量 BNB 作为 Gas。

## 五、节点与推荐

### 1. 什么是节点等级？L1～L9 分别是什么？

节点等级（**L1～L9**）代表您在推荐体系中的层级。等级越高，当**下级用户发生质押（充值）**时，您能拿到的**推荐奖励比例**越高；L4 及以上还可参与**项目分红**。

**重要**：表中的「奖励比例」指的是**按下级用户「本次质押金额」计算**的 USDT 奖励比例，不是按下级每日产生的静态收益（0.8% RWA）计算。推荐奖励**仅在下级充值/质押时触发一次**，不会每日按下级收益发佣。

### 2. 我没有下级推荐，还能赚钱吗？

**能。** 协议收益分为**静态收益**和**动态奖励**两类；**静态收益完全不依赖推荐**，没有下级一样可以赚钱。

- **静态收益（不依赖推荐）**：只要您**自己质押**了 USDT 或 RWA，就会按日获得 **RWA 代币**形式的收益（如基础 0.8% 日息 × 锁仓倍数）。这部分**与您是否有下级、是否填写推荐人无关**；您不邀请任何人，仅靠自己质押，也能持续拿每日 RWA 收益，并在「提现」页主动提现到钱包。
- **动态奖励（依赖推荐）**：只有当你**有下级用户**且他们在质押时填了您的地址作为推荐人时，您才会额外获得 **USDT** 形式的推荐/节点奖励。没有下级就没有这部分，但不影响您的静态收益。

**总结**：没有下级、没有推荐人脉，**照样可以靠质押赚取每日 RWA 静态收益**；推荐体系是在此基础上的**额外**收入，有则多拿 USDT，没有也不影响您本金产生的 RWA 收益。

### 3. 推荐人是什么？如何绑定？

**推荐人**是您**首次质押时**在「推荐人地址」一栏填写的上级用户的钱包地址。该关系在您**第一笔质押成功上链后**即**永久绑定**，无法修改。

绑定后，您**每次质押（充值）**时，您的推荐人及更上级会按各自的节点等级和「压级」规则，从**您本次质押金额**中获得一定比例的 USDT 推荐奖励（见下条）。在「节点与推荐」页可查看自己的推荐链接与下级结构；邀请好友时，让对方在**质押页**「推荐人地址」一栏**填写您的钱包地址**即可。

**举例**：小张首次质押时填了推荐人老李的地址；链上确认后，小张与老李永久绑定。之后小张每次充值质押，老李会按自己的节点比例从「小张当次质押金额」中获得 USDT 奖励；小张无法再更改推荐人。

---

#### 推荐人地址填错了怎么办？

**推荐人一经首次质押并上链确认后即永久绑定，合约不支持修改或解绑。**

- **若您还未进行过任何质押**：在第一次质押前请务必核对「推荐人地址」是否正确（建议从推荐人处复制完整 0x 地址再粘贴）。只要尚未发生首笔质押，不填或填错都不会被写入链上，您仍可重新填写正确地址后再质押。
- **若您已经完成过质押且推荐人已绑定**：链上无法更改。智能合约中未提供「修改推荐人」或「解绑推荐人」的接口，因此**无法通过页面或合约自行更正**。若填错成他人地址，后续您每次质押产生的推荐奖励会发给该错误地址；若填成 0 或未填，则首笔质押后没有推荐人，之后也无法补绑。
- **建议**：首次质押前与推荐人确认地址（可让对方发推荐链接，从链接中带出的地址一般不会错）；大额前先用小额测试并到「节点与推荐」页确认显示的推荐关系是否正确。若已绑定错误且涉及金额较大，可尝试通过官方客服/社群说明情况，看项目方是否有其他补救策略（如迁移账户等），但**合约层面无法改推荐人**。

### 4. 推荐奖励如何计算？

**触发时机**：仅当您的**下级用户发生质押（充值）**时触发，系统按**该用户本次质押金额**计算并发放 USDT 给其推荐人及更上级。**不会**在下级每日领取 0.8% 静态收益时再给推荐人分佣——即「名下用户产的每日收益」不产生推荐奖励，只有「名下用户充值」才产生。

**计算方式**：  
- 基数：**下级用户本次质押的金额**（USDT 或 RWA 等值，与合约内部精度一致）。  
- 比例：从直推开始沿推荐链往上，按各上级的**节点等级对应比例**分配；多级共存时采用**压级**（等级差）：每一级只拿「自己比例 − 已被下级占掉的比例」的差额，所有上级加总不超过本次质押金额的 **50%**。  
- **单笔上限**：每个推荐人单笔获得的奖励，不超过该推荐人**自身当前总质押的 50%**；超过部分不发放（协议内称为 burn）。

**举例**：  
- 直推用户 B **本次质押 2,000 USDT**，您为 L2（5%）、无更上级：您获得 2,000×5%＝**100 USDT**（且不超过您自身总质押的 50%）。  
- 直推用户 C **本次质押 10,000 USDT**，您为 L3（8%）：您获得 10,000×8%＝**800 USDT**；若您自身总质押只有 1,000 USDT，则单笔上限为 500 USDT，您实际只得 **500 USDT**，超出部分不发放。  
- 多级：C 的推荐人是您（L3，8%），您的推荐人是老张（L5，17%）。C 质押 10,000 USDT 时，您拿 8%＝800，老张拿等级差 17%−8%＝9%＝900，合计 1,700 USDT，低于 50% 上限。

奖励自动记入链上，您在「提现」页的 **USDT 奖励领取** 卡片中领取。

#### 为什么我的推荐奖励比预期少？

常见原因如下，可逐条对照：

**1. 奖励只按「下级本次质押金额」发，不按下级每日收益发**  
推荐奖励**仅在下级用户充值（质押）时**按**当次质押金额**的比例发放。下级每天产生的 0.8% 静态收益**不会**再给推荐人分佣。若您预期的是「按下级每日收益抽成」，协议规则并非如此，所以会感觉奖励少。

**2. 单笔奖励上限：不超过您自身总质押的 50%**  
每个推荐人从**单笔**下级质押中获得的奖励，不得超过该推荐人**自己当前总质押的 50%**，超出部分不发放。  
**举例**：您为 L3（8%），直推本次质押 10,000 USDT，按比例您应得 800 USDT；但您自己只质押了 1,000 USDT，单笔上限为 500 USDT，实际到账只有 **500 USDT**，另外 300 不会补发。

**3. 压级：您上面还有上级时，您只拿「等级差」**  
若您不是推荐链最顶端，您上面还有推荐人，则您只拿**您本等级比例 − 已被下级占掉的比例**的差额。  
**举例**：直推是您（L3，8%），您的推荐人是老张（L5，17%）。直推质押 10,000 USDT 时，您拿 8%，老张拿 17%−8%＝9%。若您误以为能拿 8% 而老张不拿，或误以为按 17% 全给老张，就会对「自己只拿 8%」感到偏少。

**4. 推荐人填错或未绑定**  
若您首笔质押时推荐人地址填错或未填，链上就没有推荐人，之后也不会补发历史推荐奖励；只有正确绑定后，**之后的**质押才会给您发推荐奖励。

**建议**：在「节点与推荐」页确认自己的等级与推荐关系；在「提现」页查看可领 USDT 及历史记录。若某笔明显偏少，可对照上述 2～4 条看是否触达单笔 50%、压级或推荐人绑定问题。

### 6. 我的节点等级降级了是怎么回事？

若协议**实现了降级逻辑**，当您的**团队总质押量**或**个人质押量**等不再满足当前等级要求时，系统可能会在定期检查（如每小时或每日）后**自动将等级调低**，以保证「等级与真实业绩」一致。

**建议**：在「节点与推荐」页查看当前等级及下一级/当前级的条件说明；若发现等级下降，对照团队量、个人质押等是否仍满足原等级。若协议**未实现降级**，则等级只升不降，您看到的变动可能来自页面缓存或数据延迟，刷新或联系客服确认即可。**具体以协议规则与官方说明为准。**

### 7. 直推和间推有什么区别？奖励怎么分？

- **直推**：您直接邀请、并在其**首次质押时填写了您的地址**作为推荐人的用户，即您的「一级下级」。  
- **间推**：您直推的用户再邀请的人（您下级的下级），相对您就是「二级、三级…」即间接推荐。

**奖励分配（压级）**：当一名下级用户质押时，其**直推**先按自己的节点等级比例从该笔质押金额中拿一部分 USDT；**间推**（更上层的推荐人）按「等级差」再拿一部分：每一层只拿「自己等级比例 − 已被下层占掉的比例」的差额，所有层加总不超过该笔质押的 **50%**。  
**举例**：用户 C 质押 10,000 USDT；C 的推荐人是您（L3，8%），您的推荐人是老张（L5，17%）。则您拿 8%（直推层），老张拿 17%−8%＝9%（间推层）；C 的直推是您、间推是老张，奖励按上述比例分，不是「各拿各的满额比例」。

**总结**：直推 = 您的一级下级，间推 = 下级的下级…；奖励按**压级**分配，上层拿「等级差」，总比例不超 50%。

#### 同一个钱包能被多人推荐吗？

要看您问的是哪一种意思：

- **同一个钱包（地址）能否作为推荐人被多人填写？**  
  **可以。** 一个钱包地址可以作为**推荐人**被无数人填写：A、B、C 首次质押时都填您的地址，您就是他们三人的共同推荐人，他们每次质押您都会按等级比例从各自当笔金额里拿推荐奖励。您的「直推」就是所有填了您地址的用户。

- **一个用户（一个钱包）能否被多人「同时」推荐？**  
  **不能。** 每个钱包地址在协议里**只能绑定一个推荐人**（首次质押时填的那个地址），绑定后不可改。不存在「多个推荐人共同推荐一个地址」的情况。

### 8. 如何升级节点等级？

等级由系统根据**团队总质押量、直推数量与结构、个人质押量**等条件**自动判定**并写回链上，**无需手动申请**。系统在每次有下级质押等事件后会检查条件，满足即自动升级。

**举例（条件仅为示意，以页面为准）**：  
- 从 L1 升 L2：个人质押 ≥ 500 USDT，且团队（含自己及下级）总质押 ≥ 5,000 USDT。  
- 从 L2 升 L3：个人质押 ≥ 1,000 USDT，团队总质押 ≥ 20,000 USDT。  
- L4～L9 需满足对应团队量及个人质押（见上表）。请在「节点与推荐」页查看**当前等级**与**下一级所需条件**。

## 六、抽奖与活动

### 1. 抽奖规则是什么？

用户使用 **RWA** 等代币**购买抽奖券**参与奖池。开奖采用链上随机数（如 **Chainlink VRF**），结果公开可查、不可篡改。

**资金分配**：每个奖池开奖时，先拿出奖池的 **5%** 转入协议**国库**；剩余 **95%** 按奖级比例分给中奖用户（一等奖 48%、二等奖 24%、三等奖 14%、四等奖 9%）。若某一奖级**无人中奖**，该奖级对应奖金**滚入下一期**同一奖池，不归项目方。

**举例**：某期周奖池共 10,000 USDT，开奖时：500 USDT（5%）进国库；4,800 给一等奖、2,400 给二等奖、1,400 给三等奖、900 给四等奖；若一等奖无人中奖，则 4,800 滚入下一周周奖池。

### 3. 开奖时间是怎么定的？（UTC）

所有奖池的开奖时刻均按 **UTC 0 时区** 的固定时间执行，由智能合约根据时间戳判定，保证全球一致：

- **月奖**：每月 1 日 00:00 UTC。
- **年奖**：每年 1 月 1 日 00:00 UTC。

**举例**：若现在是 2026 年 3 月 10 日 14:35 UTC，则下一次实时开奖为 14:40 UTC；下一次周奖为 3 月 17 日 00:00 UTC。您可在「幸运抽奖」页下方查看详细开奖时间与规则说明。

**举例**：您花 50 RWA 购买 5 张周奖券；开奖后若中四等奖，则按当周奖池的 9% 获得对应 RWA/USDT，在页面点击领取即可到账。

## 八、经济模型

### 1. 协议的资金模型是什么？（50/50）

用户**质押**时，资金按 **50% 进入国库、50% 进入社区奖励池** 的比例分配。

- **国库**：用于协议储备、安全与长期发展，用户无法在提现或紧急提取时取回已进国库部分。  
- **社区池**：专门用于发放每日 **RWA 静态收益** 与 **USDT 动态奖励**（推荐/节点）。

**举例**：100 位用户各质押 10,000 USDT，总 1,000,000 USDT；则 500,000 进国库、500,000 进社区池。日后每日发放的 RWA 与 USDT 奖励从社区池及协议规则中支出，国库部分不直接退回用户。

---

### 2. 国库和社区池是什么？

**国库（Treasury）**：  
- 接收用户质押资金的 **50%**。  
- 用途：协议储备、运营、安全与生态建设等。  
- 抽奖奖池中也有 **5%** 进入国库。

**社区池（Community Pool）**：  
- 接收用户质押资金的另外 **50%**。  
- 用途：向用户发放 RWA 静态收益与 USDT 动态奖励。

**举例**：单笔 2,000 USDT 质押 → 1,000 进国库、1,000 进社区池；某期抽奖奖池 20,000 USDT → 1,000（5%）进国库，19,000 按奖级分给中奖用户或滚入下期。

### 3. 抽奖奖池中 5% 进国库是什么意思？

每个抽奖奖池在**分配时**，会先拿出奖池总额的 **5%** 转入协议**国库地址**，用于项目运营与生态；剩余 **95%** 按以下比例分配给中奖用户（若某奖级无人中奖则滚入下一期）：

| 奖级   | 比例 | 举例（奖池 10,000 USDT） |
|--------|------|---------------------------|
| 一等奖 | 48% | 4,800 USDT               |
| 二等奖 | 24% | 2,400 USDT               |
| 三等奖 | 14% | 1,400 USDT               |
| 四等奖 | 9%  | 900 USDT                 |
| 国库   | 5%  | 500 USDT                 |

**举例**：奖池 50,000 USDT，则 2,500 进国库；若一等奖无人中奖，4,800 不归项目方，而是滚入下一期该奖池，下一期一等奖奖金 = 原定 48% + 本期滚入的 4,800。

### 2. 协议会跑路吗？资金安全怎么保障？

这是很多用户最关心的问题，我们正面说明协议在设计和运营上如何保障资金安全、降低「跑路」风险：

**① 多签管理国库，不能单人动款**  
协议**国库**（接收用户质押 50%、抽奖奖池 5% 等资金）由 **Gnosis Safe 多签钱包**管理，采用 **3/2 多签**：即至少需要 3 个签名者中的 **2 人**共同签名才能转出资金，任何单一人员无法单独动用国库。这样从机制上避免「一个人卷款跑路」。

**② TimeLock（时间锁）约束参数变更**  
关键**参数变更**（如费率、限额等）如通过 TimeLock 合约执行，会有一段时间的**锁定期**（例如 48 小时）。在锁定期内，拟变更内容会在「治理」页公示，社区可查看并反应；到期后才会真正生效。这减少了「悄悄改规则、损害用户」的可能，提高可预期性和透明度。

**③ 第三方安全审计**  
智能合约已通过 **SlowMist** 和 **CertiK** 两家独立机构的安全审计，审计报告在官网「安全与审计」页公开可查。审计有助于发现漏洞与不当权限，项目承诺在重大升级前再次审计，从代码层面降低被攻破或恶意利用的风险。

**④ 国库与资金流透明可查**  
国库地址、合约地址在官网**治理/透明性**页面公示；用户与社区可在 BSC 区块浏览器上**直接查询**国库余额、大额转入转出等链上记录。资金流向可追溯，有利于社区监督，也便于发现异常。

**⑤ 合约逻辑：用户资金不经过项目方私钥**  
您质押的 USDT/RWA 按合约规则**直接进入合约或国库多签地址**，提现与收益发放由**智能合约规则**执行，不依赖项目方「手动打款」。只要合约未被攻破、未被人为恶意升级，用户按规则操作即可取回可提部分。

**风险提示**：以上措施可以显著降低中心化「跑路」和单点作恶风险，但**无法绝对排除**合约漏洞、极端情况或外部攻击。DeFi 仍存在智能合约风险与市场风险，请仅投入您可承受损失的资金，并持续关注官网与公告。

### 10. 如果协议停止运营，我的资金能取回吗？

- **建议**：协议方若公告停运，通常会说明合约是否保持可调用、提现是否仍可进行；您可保存**合约地址与 ABI**，必要时在 BSCScan 等区块浏览器上直接与合约交互。最坏情况下能否取回、能取回多少，以合约实际状态与公告为准。

### 11. BSC 链出问题会影响我的收益吗？

**会。** 收益的结算、发放与提现都依赖 **BSC（币安智能链）** 正常出块与合约执行；链一旦出现长时间宕机、分叉、严重拥堵或安全事件，可能带来以下影响：

- **结算延迟**：每日收益由后端或链上逻辑在固定时间触发；若当时 BSC 异常，结算可能延迟或当次未执行，需等链恢复后补算或顺延（以协议实际设计为准）。
- **无法提现/领取**：提现与领取需要向合约发送交易；若链暂停出块或 RPC 不可用，您无法成功发起交易，资金会暂时「卡」在合约里，直到链恢复。
- **极端情况**：若 BSC 发生不可逆的链级别故障或弃用，合约与资产的状态取决于 BSC 官方与社区的处置（如迁移、快照等），非单协议能完全控制。

**总结**：BSC 是协议运行的基础设施，链级风险会传导到收益与资金操作；属于**系统性风险**，建议了解后理性参与。协议无法为链本身的问题兜底。

## 十、常见对比与操作

### 1. RWA 和 PancakeSwap 流动性挖矿有什么区别？

- **PancakeSwap 流动性挖矿**：您提供**交易对流动性**（如 USDT-BNB），获得**手续费分成 + 挖矿奖励代币**，收益与池子交易量、APR 相关；可随时**撤池**取回本金（含无常损失风险）。
- **RWA 协议质押**：您将 **USDT 或 RWA** 存入协议合约，获得**每日 RWA 收益**（如 0.8% 日息 × 锁仓倍数）及可能的**推荐/节点 USDT 奖励**；本金仍按 **50/50** 进入国库侧与合约侧记账，但退出方式取决于仓位类型：**USDT 灵活本金**可正常提取，**USDT 锁仓本金**到期后可正常提取、未到期则按已完成天数走紧急退出，**RWA 本金**则按灵活/到期锁仓路径提取。
- **简要对比**：流动性挖矿偏「做市 + 挖矿奖励」、可撤池；RWA 质押偏「固定收益 + 推荐体系 + 按仓位类型区分退出路径」，参与前要先看清自己是哪种本金仓位。

---

### 2. RWA 和其他高收益质押平台有什么不同？

- **收益来源**：RWA 协议以**每日静态 RWA 收益 + 推荐/节点 USDT 动态奖励**为主，比例与锁仓、等级挂钩；其他平台可能是纯 APY 挖矿、双币理财等，结构和风险不同。
- **本金与退出**：RWA 采用 **50/50 记账机制**，但现在本金退出路径已明确区分：**灵活本金**可走正常本金提取，**到期锁仓本金**可走正常到期提取，只有**未到期锁仓 USDT** 才会使用按已完成天数计算的紧急退出。不要把所有本金都理解成同一种退出逻辑。
- **透明与安全**：RWA 提供**多签国库、TimeLock、第三方审计、链上可验证的 TVL/国库**等；可对比其他平台是否合约开源、审计公开、资金是否链上可查，以区分正规协议与高风险项目。

**建议**：不因「高收益」就盲目参与；看清本金是否可退、收益从何而来、是否有审计与链上透明，再决策。

### 3. 质押时填错金额，交易已发出能撤回吗？

**链上交易一旦发出且被节点打包，通常无法撤回或改额。** 协议合约也没有「撤销上一笔质押」的接口。

- **若交易仍在 Pending**：可在钱包里对该笔交易**取消（Cancel）** 或**加速并改为 0 金额**（视钱包是否支持），避免错误金额被打包。
- **若已确认**：错误金额的质押已生效，无法通过协议或链上操作「退回」或「改数」。若多打了，多出的部分会按规则参与质押与收益；若少打了，可再发起一笔质押补足。**下单前务必核对金额与锁仓期。**

### 4. 我能把质押份额转给别人吗？

**不能。** 协议**不支持**将您名下的质押份额或「仓位」转让给其他地址。

- 质押与收益均**绑定在您的钱包地址**上；合约没有「转移质押份额」「过户」等函数。若您希望他人享有收益，只能由对方**用自己的地址**参与质押；您无法把当前地址的质押「转给」对方。
- 若您不再使用该地址，只能通过**提现、领取、紧急提取**等把可操作资产转出到您控制的其他地址，而不能把「未到期质押」本身转户。

### 5. 节点推荐链接在哪里生成？

在「**节点与推荐**」页（导航中多为「节点」/「推荐」/「Nodes」等）：  
页面内会展示您的**推荐链接**（通常为官网 URL + 您的钱包地址或推荐码）。您可直接**复制链接**发给好友；对方打开链接后，在**质押页**首次质押时，推荐人地址栏会**自动带出您的地址**（若未带出，需对方手动粘贴您的地址）。  
若找不到入口，请查看顶部或底部导航中的「**节点**」「**推荐**」「**我的推荐**」等；部分产品也会在质押页提供「获取推荐链接」入口。

### 6. 收益计算器在哪里？怎么用？

在网站导航中进入「**收益计算器**」或「**Calculator**」（多与「数据分析」「Analytics」等同组）。  
**怎么用**：输入**质押金额**、**锁仓期限**（灵活/30/90/180/365 天）、**节点等级**（若需估算推荐收益）等，页面会按协议规则估算**每日/每月/每年**的 RWA 收益及可能的 USDT 动态奖励，**仅供参考**，不构成链上承诺。实际收益以链上结算与合约为准。使用计算器可快速试算不同金额与锁仓组合的大致回报。
