# Hardhat 本地链重启与部署

## 一键执行（推荐）

在项目根目录执行：

```powershell
.\scripts\restart-local-and-deploy.ps1
```

脚本会：

1. 结束占用 `8545` 的旧进程（若有）
2. 启动 Hardhat 节点（后台，`http://127.0.0.1:8545`）
3. 部署全部合约并完成配置：
   - 向测试地址 `0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266` 铸造 **100,000 USDT**
   - 该地址为 Hardhat 账户 #0（部署账户），同时持有 RWA 初始供应
4. 自动写入：
   - `backend/.env`：`RPC_URL`、`STAKING_CONTRACT_ADDRESS` 等
   - `frontend/.env.local`：本地合约地址
   - `frontend/lib/contracts/addresses.ts`：本地 fallback 地址

## 分步执行

### 1. 启动节点

```bash
npm run node
```

或：

```bash
npx hardhat node
```

保持终端不关。

### 2. 新开终端，部署并配置

```bash
npm run deploy:local
```

或：

```bash
npx hardhat run scripts/deploy-local-test.ts --network localhost
```

### 3. 启动前端与后端

```bash
# 前端
cd frontend && npm run dev

# 后端（另开终端）
npm run backend:dev
```
