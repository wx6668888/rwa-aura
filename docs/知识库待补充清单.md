## 一、高优先级（用户常问、影响理解）

### 1. 提现与本金

| 建议 ID | 标题（中文） | 说明 |
|--------|--------------|------|
| `principal-withdraw-guide` | 如何提取本金？灵活/锁仓本金怎么提？ | 独立一篇「本金提取指南」：提现页**本金提取区**的四种类型（USDT 灵活、USDT 到期锁仓、RWA 灵活、RWA 到期锁仓）、入口在哪、立即到账 8% 与 stRWA 模式 0%+120% 选择。当前仅在「如何提现 RWA 收益？」中顺带写，单独一篇更清晰。 |
| `rewards-manual-claim` | 收益是自动到账还是要手动领取？ | 说明 RWA 收益与 USDT 奖励都需用户在「提现」页**主动操作**才会到账，不会自动打款。 |
| `withdraw-amount-mismatch` | 为什么可提 RWA 金额和我算的不一样？ | 说明链上按 RWA **数量**记、价格波动、最低 100 与 8% 手续费等导致和「本金×日息×天数」毛估不一致，建议以页面/链上为准。 |
| `withdraw-not-received` | 提现后 RWA 没到钱包怎么查？ | 排查：BSC 网络与地址、钱包是否添加 RWA 代币、BSCScan 查 TX、刷新延迟、联系客服带 TX Hash。与「奖励没到账」区分开（后者偏收益未结算）。 |
| `rwa-usdt-separate-claim` | USDT 奖励和 RWA 收益要分开领取吗？ | 说明是两个入口：RWA 提现卡片 vs USDT 奖励卡片，需分别操作，各消耗 Gas。 |

### 2. 节点与推荐

| 建议 ID | 标题（中文） | 说明 |
|--------|--------------|------|
| `no-referrals-still-earn` | 没有下级推荐还能赚钱吗？ | 强调**静态收益不依赖推荐**，无下级也可拿每日 RWA 收益；推荐是额外 USDT 收入。 |
| `wrong-referrer-address` | 推荐人地址填错了怎么办？ | 首笔质押上链后**永久绑定、合约不可改**；未质押前可改；已绑错只能通过客服等非合约方式尝试处理。 |
| `node-level-downgrade` | 节点等级降级是怎么回事？ | 说明等级按**当前**团队/个人质押等条件动态计算，条件不满足会降级，再满足会恢复。 |
| `direct-vs-indirect-referral` | 直推和间推有什么区别？奖励怎么分？ | 说明直推/间推在推荐链上的位置，以及「压级」：每级只拿自己比例减掉下级已拿部分，总和不超 50%。 |

### 3. 质押操作

| 建议 ID | 标题（中文） | 说明 |
|--------|--------------|------|
| `what-is-approve` | 授权（Approve）是什么？为什么要两笔交易？ | 首次对 USDT/RWA 等授权合约扣款，授权成功后再执行质押/兑换，避免一笔交易做两件事导致失败。 |
| `balance-insufficient-why` | 显示「余额不足」但钱包里有 USDT？ | 常见原因：未选 BSC、未授权或授权额度不足、预留 Gas 的 BNB 不足、代币合约地址不一致等。 |
| `can-cancel-stake` | 我能取消质押吗？ | 说明没有「一键取消」；需按**仓位类型**走对应退出：灵活本金提取、到期锁仓到期提取、未到期锁仓 USDT 可紧急退出等。 |
| `multiple-stakes` | 可以同时有多笔质押吗？ | 可以。同一地址可多笔、不同锁仓期，总质押与收益合并计算，仪表板/提现页会汇总展示。 |
| `strwa-vs-rwa` | stRWA 和 RWA 有什么区别？ | stRWA 是**锁仓 RWA 的凭证**，锁仓期内不能当 RWA 转出；到期后通过「stRWA 解锁」换回 RWA。RWA 是自由流通代币。 |

## 四、实施建议

1. **先做高优先级**：尤其是「本金提取指南」「收益是否自动到账」「可提金额不一致」「没推荐能否赚钱」「推荐人填错」等，用户问得多且易误解。
2. **与 knowledge-data 同步**：每篇新文章需在 `knowledge-data.ts` 的对应分类下增加一条，并分配 `id`、`titleKey`、`contentKey`。
3. **多语言**：新增条目在 `knowledge-content-zh-full.ts` 与 `knowledge-content-en-full.ts` 中先补齐，其他语言可后补或沿用英文 fallback。
4. **与 Markdown 文档对齐**：上述标题与《知识库完整文案-中文.md》中对应小节一致，可直接从文档摘编或改写后填入各 `*-full.ts`。
