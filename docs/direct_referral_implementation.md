# 直推奖励系统实现说明（已修正）

## 一、核心规则

### ✅ 正确理解
1. **只奖励直接推荐人**（一级）
2. **锁仓要求**：下级必须选择≥30天的锁仓订单
   - ✅ 30天、90天、180天、365天锁仓 → 触发奖励
   - ❌ 灵活质押（0天） → 不触发奖励
3. **立即记录**：符合条件立即记录为MATURED状态
4. **每周结算**：每周一凌晨批量发放

### 奖励计算
- USDT质押：`奖励 = 质押金额 × 推荐人等级比例`
- RWA质押：`奖励 = (RWA × 0.85) × 推荐人等级比例`

### 等级比例
L1: 3%, L2: 5%, L3: 8%, L4: 12%, L5: 17%
L6: 23%, L7: 30%, L8: 35%, L9: 40%

## 二、工作流程

```
质押事件（lockPeriod ≥ 30）
    ↓
后端监听
    ↓
检查锁仓期（< 30天则跳过）
    ↓
记录奖励（状态：MATURED）
    ↓
每周一结算 → 批量发放USDT → 状态：PAID
```
