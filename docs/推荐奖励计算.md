# 推荐奖励计算与发放

## 📊 核心规则

### 1. 基本条件
- **只奖励直接推荐人**（一级推荐）
- **下级必须锁仓满30天**才发放奖励（灵活质押不发放）
- **每周结算一次**（每周一 02:00）
- **奖励以USDT发放**到ReferralRewardPool合约

### 2. 等级奖励比例

| 推荐人等级 | 奖励比例 |
|-----------|---------|
| L1 | 3% |
| L2 | 5% |
| L3 | 8% |
| L4 | 12% |
| L5 | 17% |
| L6 | 23% |
| L7 | 30% |
| L8 | 35% |
| L9 | 40% |

## 🔢 计算逻辑

### USDT质押的推荐奖励

**公式**：
```
奖励金额(USDT) = 质押金额(USDT) × 推荐人等级比例
```

**示例**：
- 下级质押 10,000 USDT，锁仓30天
- 推荐人等级 L5（17%）
- 奖励 = 10,000 × 17% = **1,700 USDT**

### RWA质押的推荐奖励

**公式**：
```
1. 还原RWA原始金额 = 合约金额 / 0.85
2. 计算奖励 = RWA原始金额 × 推荐人等级比例
3. 转换为USDT = 奖励 × 0.85
```

**示例**：
- 下级质押 1,000 RWA，锁仓90天
- 合约记录金额：850 USDT等值
- 还原RWA：850 / 0.85 = 1,000 RWA
- 推荐人等级 L3（8%）
- 奖励RWA = 1,000 × 8% = 80 RWA
- 转换USDT = 80 × 0.85 = **68 USDT**

## ⏰ 发放流程

### 步骤1：记录奖励（质押时）

当用户质押时，系统自动检查：
1. 是否有推荐人
2. 锁仓期是否≥30天
3. 推荐人等级

如果满足条件，记录到`direct_referral_rewards`表：
- 状态：PENDING
- 到期时间：质押时间（立即可结算）

### 步骤2：周结算（每周一 02:00）

**定时任务**：`'0 2 * * 1'`（每周一凌晨2点）

**处理流程**：
1. 创建结算批次（batch_number）
2. 查询所有PENDING状态的奖励
3. 按推荐人地址汇总金额
4. 调用ReferralRewardPool合约批量充值
5. 更新奖励状态为SETTLED

### 步骤3：链上发放

**合约调用**：
```solidity
function batchDeposit(
    address[] calldata users,
    uint256[] calldata amounts
) external
```

**参数**：
- users: 推荐人地址数组
- amounts: USDT金额数组（6位小数）

**示例**：
```javascript
users = [
  "0xABC...",
  "0xDEF..."
]
amounts = [
  1700000000,  // 1,700 USDT
  68000000     // 68 USDT
]
```

### 步骤4：用户提取

推荐人可以在前端「提现」页面：
1. 查看可提取的推荐奖励
2. 点击「提现」按钮
3. 调用ReferralRewardPool.withdraw()
4. 扣除8%手续费后到账

**最低提现**：100 USDT

## 📝 数据库表

### direct_referral_rewards

| 字段 | 说明 |
|------|------|
| referrer_address | 推荐人地址 |
| referee_address | 被推荐人地址 |
| stake_id | 质押ID |
| stake_amount | 质押金额（原始金额） |
| stake_type | 质押类型（USDT/RWA） |
| referrer_level | 推荐人等级 |
| reward_rate | 奖励比例（基点，如300=3%） |
| reward_amount | 奖励金额（USDT） |
| stake_time | 质押时间 |
| maturity_time | 到期时间 |
| status | 状态（PENDING/SETTLED） |
| paid_time | 发放时间 |

### referral_settlement_batches

| 字段 | 说明 |
|------|------|
| batch_number | 批次号 |
| start_time | 开始时间 |
| end_time | 结束时间 |
| total_rewards | 总奖励金额 |
| total_records | 总记录数 |
| status | 状态（PROCESSING/COMPLETED/FAILED） |
| completed_at | 完成时间 |
