# 国内网络下连接钱包（解决一直转圈）

当前若部署在 **BSC 测试网（测试链）**，连接钱包时用的就是测试网 RPC，不是主网。测试网默认已改为国内更易访问的节点。

## 原因简述

- **RPC 节点**：默认的 BSC 公共节点（如 binance.org）在国内访问慢或被限，链上请求超时会导致页面/连接一直转圈。
- **WalletConnect 中继**：扫码或「在钱包 App 中继续」会走 WalletConnect 官方 relay，在国内可能不稳定，也会表现为一直转圈。

## 已做优化

1. **BSC RPC 使用国内更易访问的节点**  
   项目已默认使用 `https://bsc-dataseed1.defibit.io` 作为 BSC 主网 RPC。若仍转圈，可在服务器或构建环境配置下面环境变量，改用其他节点：

   ```bash
   # 可选：BSC 主网 RPC（国内可访问的节点）
   NEXT_PUBLIC_BSC_RPC_URL=https://bsc-dataseed1.defibit.io
   # 或尝试
   # NEXT_PUBLIC_BSC_RPC_URL=https://bsc-dataseed1.ninicoin.io
   # NEXT_PUBLIC_BSC_RPC_URL=https://bsc.publicnode.com

   # 可选：BSC 测试网
   NEXT_PUBLIC_BSC_TESTNET_RPC_URL=https://data-seed-prebsc-1-s1.binance.org:8545
   ```

   配置后需重新构建前端并部署。

2. **推荐使用钱包内置浏览器**  
   - 用 **OKX App** 或 **币安 App** 内置浏览器打开 `https://kelian.dpdns.org`，再在页面里点「连接钱包」选对应钱包。  
   - 内置浏览器走 App 自己的网络与 relay，往往比 Safari/Chrome 直连更稳定，可减轻「一直转圈」现象。

## 若仍然转圈

- **优先**：用 OKX/币安 App 内置浏览器访问站点后再连接钱包。  
- **其次**：确认已配置上述 `NEXT_PUBLIC_BSC_RPC_URL` 并重新部署；可多试几个上面的 RPC 节点。  
- **最后**：若 WalletConnect 中继在国内仍不可用，可暂时使用「科学上网」后再连接；或仅使用「小狐狸」等注入式钱包在 PC 浏览器连接（不依赖扫码）。

## 环境变量汇总（生产部署）

在宝塔或部署环境中可增加：

```bash
NEXT_PUBLIC_BSC_RPC_URL=https://bsc-dataseed1.defibit.io
NEXT_PUBLIC_BSC_TESTNET_RPC_URL=https://data-seed-prebsc-1-s1.binance.org:8545
NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID=你的_project_id
```

修改环境变量后需重新执行 `npm run build` 并重启/刷新前端。
